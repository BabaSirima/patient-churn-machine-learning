# Data

This directory is reserved for the Patient Churn dataset used by the notebook.

Before uploading the CSV to a public GitHub repository, verify that the dataset license permits redistribution.

If redistribution is not permitted:

1. Do not commit the CSV file.
2. Add `data/*.csv` to `.gitignore`.
3. Provide the original public dataset link in the main `README.md`.
4. Tell users where to place the downloaded file before running the notebook.

Expected notebook filename can be adjusted as needed, for example:

`data/patient_churn_dataset.csv`
